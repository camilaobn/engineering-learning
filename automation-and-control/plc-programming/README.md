
# PLC Programming

Personal learning resources, theoretical notes and practical exercises related to Programmable Logic Controllers (PLCs).

## Theory

Topics covered in this section:

- PLC Fundamentals
- IEC 61131-3
- Ladder Diagram (LD)
- Function Block Diagram (FBD)
- Structured Text (ST)
- Timers, Counters and Sequential Logic
- CODESYS

## Practical Work

### Robotics Manufacturing Systems — BME

Laboratory exercises developed using CODESYS as part of the Robotics Manufacturing Systems course at Budapest University of Technology and Economics.

Laboratory exercises will be documented here, including implementation, control logic and results.

## Learning Objectives

- Understand PLC architecture and operation.
- Develop and interpret PLC programs.
- Apply automation concepts to practical systems.
- Document and analyse technical solutions.
